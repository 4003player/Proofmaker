# Proofmaker

**Proof Sheet Generator** — browser-based tool for WAC (Westamerica Communications) that creates customer-ready proof PDFs from uploaded artwork.

**Live:** https://4003player.github.io/Proofmaker/  
**Repo:** https://github.com/4003player/Proofmaker.git  
**Stack:** Single-file `index.html` (~4,750 lines), no build step, GH Pages hosted.

## Architecture

- **PDF.js 3.x** (legacy build, no ES modules) — renders PDF pages to canvas for preview
- **jsPDF** — generates the final proof PDF (not pdf-lib; this is the only project using jsPDF for output)
- **pako** — zlib inflate for decompressing PDF content streams
- **UTIF.js** — TIFF decoding (Chrome/Edge lack native TIFF support)
- All libs loaded via CDN `<script>` tags

## Key Features

- Multi-substrate support (different paper stocks per page)
- Spot color detection and listing (79+ references in codebase)
- CMYK simulation for on-screen preview
- Die line / CutContour detection and display
- TrimBox-aware (43 refs) — TrimBox is the material edge, not MediaBox
- Deduplication of identical pages
- WAC logo overlay on proofs

## Critical Rules

1. **NEVER push to GitHub without Scott testing first** — this is production tooling used by the shop
2. **Safari compatibility required** — shop Macs run Safari; watch for "can't access property X, Y is undefined" errors
3. **`numVal()` helper** — use for all numeric input parsing (Safari input element quirk)
4. **Canvas cap 4000px** — max canvas dimension; use `toDataURL()` → `atob()` → `Uint8Array` for image extraction
5. **PDF.js 3.x only** — do NOT upgrade to PDF.js 4.x; the legacy build pattern (no ES modules) is intentional for the single-file architecture

## Spot Color Detection

Uses backward-scan approach: find `/Separation` and `/DeviceN` color spaces in page resources, parse the spot color names, detect which are used in the content stream via CS/cs operators.

## Style

Apple-inspired light theme: `#f5f5f7` background, `#1d1d1f` text, `#0071e3` accent, `-apple-system` font stack, rounded corners (`border-radius: 14px`), subtle shadows. All other tools match this theme.
